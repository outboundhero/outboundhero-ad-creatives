# OutboundHero ad creatives

Public hosting for OutboundHero Meta ad images and videos. Claude pushes new creative here, then pulls it into the Meta ad account (741433832198140) by URL.

## Workflow
1. New batch goes in a dated folder, for example `2026-11-videos/`.
2. Claude pushes it, then uploads each file to Meta with `https://raw.githubusercontent.com/outboundhero/outboundhero-ad-creatives/main/<folder>/<file>`.
3. Claude builds new ads as drafts. Nothing goes live until Spencer approves.
